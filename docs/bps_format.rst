BPS
-----

The 'BPS' is Iconeus' 'Brain Positioning System', a 4x4 transform matrix from Brain space to Lab space (Also called Brain to Lab transform (B2L))

Data
++++

data : np.ndarray
	The 4x4 transform matrix
